# Semantic grading rubric

Score the learner's expressed meaning, not lexical overlap.

1. Assign each required concept equal weight unless the card itself clearly marks a
   concept as foundational.
2. Count a concept as covered when the answer states it directly, gives a valid
   consequence that entails it, or uses an accepted equivalent formulation.
3. Do not penalize brevity, grammar, or vocabulary unless they obscure meaning.
4. Subtract for explicit contradictions. A contradiction of the learning objective
   caps the score below 0.45 even if other terms happen to match.
5. Treat an omitted required concept as missing, not contradicted.
6. Use source evidence to resolve factual ambiguity; do not silently expand the
   rubric from model memory.
7. Set confidence below 0.70 when the answer is ambiguous, the rubric is
   underspecified, or source evidence conflicts.

Use these interpretation anchors:

- `0.00-0.44`: absent, materially wrong, or contradicted understanding.
- `0.45-0.69`: partial recall with important missing content.
- `0.70-0.89`: substantially correct with a minor omission or imprecision.
- `0.90-1.00`: complete and meaningfully correct.

Return concrete covered, missing, and contradicted concept lists. Keep feedback brief.
